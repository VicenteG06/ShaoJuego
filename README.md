# INSTRUCCIONES DE INSTALACIÓN SHAODEVORADORES

## REQUISITOS
Para poder utilizar el videojuego **ShaoDevoradores** es necesario contar con:
- *Eclipse IDE for Java Developers*
- JDK 8

## INSTRUCCIONES
### PASO 1: Descomprimir el archivo .zip
Descomprime el archivo comprimido del proyecto en una ubicación fácil de encontrar en tu computadora.

### PASO 2: Abrir Eclipse
Abre Eclipse IDE y selecciona o crea un espacio de trabajo (*workspace*).

### PASO 3: Importar el proyecto
En el menú superior, selecciona **File** (Archivo) y luego **Open Projects from File System...** (o bien, **Import** > **General** > **Existing Projects into Workspace**).

### PASO 4: Seleccionar la carpeta
En la ventana que aparece, haz clic en el botón **Directory...** (Directorio) y busca la carpeta donde descomprimiste el proyecto. 

### PASO 5: Finalizar la importación
Asegúrate de que el proyecto aparezca seleccionado en la lista de "Projects" detectados y haz clic en **Finish**.

### PASO 6: Ejecutar el juego
1. En el panel izquierdo (*Package Explorer*), despliega la carpeta del proyecto y busca la clase principal del juego (la que contiene el método `public static void main`).
2. Haz clic derecho sobre esa clase, selecciona **Run As** y luego **Java Application**.
